# Steam FPS

Простой калькулятор производительности для игр из библиотеки Steam.

Приложение автоматически определяет процессор, видеокарту и оперативную память вашего ПК, после чего рассчитывает примерный FPS для разных настроек графики (Low, Medium, High, Ultra) и разрешений.

![Иконка](app_icon.png)

## Что умеет
* В базе более 2800 игр (включая VR и популярные инди).
* Автоматически определяет характеристики ПК при запуске.
* Показывает диапазон FPS, средний фреймрейт и возможные просадки (1% Low).
* Если нужной игры нет в каталоге — можно ввести её Steam AppID из магазина, и она добавится в поиск.
* Работает как один `.exe` файл — запускается сразу, без установки и сторонних DLL.

## Как запустить
1. Скачайте `Steam_FPS.exe` в разделе [Releases](../../releases).
2. Запустите файл на Windows 10 или 11.
